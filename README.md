# packages

APT and DNF repositories for [certstream-server-rust](https://github.com/reloading01/certstream-server-rust).

The `gh-pages` branch is generated by the release workflow in the main
repository and rewritten on every release, so it carries no history. Do not
commit to it by hand.

Installation instructions are served at
[reloading01.github.io/packages](https://reloading01.github.io/packages/).
